# Barbara Herrera — Experience Design Portfolio

This repository contains my personal portfolio as an MSc Experience Design student at Halmstad University.

The portfolio documents selected projects from my studies, with a focus on the design process, research, decisions, prototyping and reflection.

## Selected Projects

### Full Fridge

**Improving the shared fridge experience and storage organisation**

An Experience Design project exploring how students use shared refrigerators at Halmstad University, moving from research and observation to physical and interactive prototyping.

The project is currently in development and will be added to the portfolio as the work progresses.

## About me

I am currently studying a MSc in Experience Design at Halmstad University.

My work explores how research, interaction and prototyping can be used to understand and improve everyday experiences.
